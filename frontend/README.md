# Frontend

Korisnički interfejs aplikacije **TokenLedger**: dashboard za praćenje potrošnje tokena i troškova AI alata.

## Šta ide u ovaj folder

- Kod korisničkog interfejsa (stranice, komponente, stilovi)
- Dashboard sa grafikonima i tabelama potrošnje
- Komunikacija sa backend API-jem
- Frontend testovi
