# Dokumentacija

Ovde se čuva sva dokumentacija projekta **TokenLedger**.

## Šta ide u ovaj folder

- Koncept aplikacije i opis problema koji rešavamo
- Arhitektura sistema i dijagrami
- Model baze podataka
- API dokumentacija
- Korisnički tokovi i skice ekrana (wireframes)
- Materijali za takmičenje InnovNation (prezentacija, pitch, prijava)
- Beleške sa sastanaka i donete odluke

## Predložena struktura

```
docs/
├── concept.md        # koncept i vizija
├── architecture.md   # arhitektura i izbor tehnologija
├── api.md            # opis API endpointa
├── database.md       # model baze
└── innovnation/      # materijali za takmičenje
```

## Pravila

- Dokumentacija se piše u Markdown (`.md`) formatu.
- Slike i dijagrami idu u poseban podfolder (npr. `docs/images/`).
- Menja se kroz Pull Request kao i kod, prema [CONTRIBUTING.md](../CONTRIBUTING.md).
