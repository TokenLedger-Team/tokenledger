# Dizajn

Originalni prototipovi dizajna, sačuvani kao referenca. **Ovo nije kod aplikacije**; aplikacija je u [`frontend/`](../../frontend/).

| Folder | Šta je |
|---|---|
| `login/` | Stranica za prijavu (Google, email/lozinka, animirani teserakt) |
| `dashboard/` | Prototip celog dashboarda sa 7 modula (statični demo podaci) |

Oba prototipa se otvaraju direktno u browseru (`index.html` / `login.html`), bez servera.
Kako je dizajn povezan sa pravim podacima opisano je u [`frontend/API.md`](../../frontend/API.md).
