# Backend

Serverski deo aplikacije **TokenLedger**: API, poslovna logika i baza podataka za evidenciju potrošnje tokena i troškova AI alata.

## Šta ide u ovaj folder

- API endpointi (unos potrošnje, pregled, izveštaji)
- Autentikacija i uloge korisnika (admin / menadžer / zaposleni)
- Obračun troškova, budžeti i upozorenja
- Model baze podataka i migracije
- Backend testovi
